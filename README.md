# Поиск похожих рыночных ситуаций

Мобильное веб-приложение на Streamlit для анализа исторических свечей Bybit USDT linear.

## Запуск локально

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Развёртывание в Streamlit Community Cloud

1. Загрузить этот проект в GitHub-репозиторий.
2. В Streamlit Community Cloud создать приложение из этого репозитория.
3. Указать `app.py` как основной файл.

Приложение использует публичный API Bybit и не требует API-ключа. Исторические результаты — исследовательская информация, не гарантия прогноза.
