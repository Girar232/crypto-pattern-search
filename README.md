# Поиск похожих рыночных ситуаций

Мобильное веб-приложение на Streamlit для поиска похожих рыночных ситуаций. Приложение читает SQLite-базу свечей, поэтому во время анализа не обращается к бирже.

## Запуск локально

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Обновление базы Bybit

На компьютере, где доступен публичный API Bybit, выполни:

```powershell
.venv\Scripts\python.exe update_database.py
```

Для пустой пары скрипт загружает начальную историю до 10 000 свечей на таймфреймах `1h`, `15m` и `4h`. При следующих запусках он добавляет только новые закрытые свечи; уже сохранённые закрытые свечи не перезаписываются и не удаляются. Чтобы обработать один интервал, передай `--interval`, например `--interval 4h`. Контракты, которые API не вернёт, будут показаны в списке ошибок; в веб-приложении отображаются только контракты, данные которых есть в базе. Таймфрейм `1h` выбран по умолчанию.

Команда выше обновляет **все три интервала** для всех контрактов. Чтобы обновить только один интервал, укажи его явно:

```powershell
.venv\Scripts\python.exe update_database.py --interval 4h
```

Вместо `4h` можно указать `1h` или `15m`.

Чтобы обновить базу в опубликованном приложении, отправь изменённый файл `market_data.sqlite` в приватный GitHub-репозиторий. Streamlit Cloud обновит приложение из репозитория.

## Развёртывание в Streamlit Community Cloud

1. Загрузить этот проект в GitHub-репозиторий.
2. В Streamlit Community Cloud создать приложение из этого репозитория.
3. Указать `app.py` как основной файл.

В приложении по умолчанию выбрана Bybit Perpetual. Binance Futures появится в списке контрактов, когда в базу будут добавлены данные Binance. Обновление Binance пока не настроено. Исторические результаты — исследовательская информация, не гарантия прогноза.
